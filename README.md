# Fix Mama 😎

### Your voice. Your complaint. Your community.

Fix Mama is an accessible multilingual civic complaint assistant designed to make reporting public problems simpler and easier.

Users can verify their phone number, choose their preferred language, upload or capture a photo, select the type of civic issue, provide relevant context and location, review the complaint, and send it through a guided workflow.

## 🚀 Features

* 📱 OTP-based login
* 🌐 Multilingual support

  * Telugu
  * English
  * Hindi
* 📸 Capture or upload an image of the civic issue
* 🛣️ Simple civic problem categories
* 📍 Browser-based location support
* 🔊 Speaker-enabled options using text-to-speech
* 🏫 Context selection for important nearby locations
* 📝 Guided complaint creation and review
* 📋 Simple and accessible user interface

## 🛠️ Technology Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Responsive Web Design
* Browser Geolocation API
* Web Speech / SpeechSynthesis API

## ♿ Accessibility

Fix Mama focuses on making civic reporting easier for people who may face difficulties with conventional text-heavy complaint forms.

The platform uses:

* Large and easy-to-understand options
* Multilingual interface
* Speaker-enabled choices
* Photo-based reporting
* Guided step-by-step workflow
* Reduced dependence on typing

## 🎯 Problem We Address

Reporting everyday civic issues can be difficult when users have to navigate complicated forms, type detailed descriptions, or interact with systems available in limited languages.

Fix Mama simplifies this process by guiding users through a visual, multilingual and accessibility-focused complaint workflow.

## 💻 Getting Started

### Prerequisites

Make sure you have:

* Node.js installed
* npm installed

### Installation

Clone the repository:

```bash
git clone https://github.com/Sunitha-Y7/fix-mama.git
```

Open the project folder:

```bash
cd fix-mama
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.
